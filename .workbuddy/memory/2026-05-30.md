### 第二轮 (晚上)：构建打通 + API 验证 ✅

**绕过 NuGet 沙箱问题**
- 沙箱阻止 `C:\ProgramData\NuGet\Config` 目录创建，dotnet restore 始终失败
- 解决方案：手动下载 5 个 NuGet 包 (.nupkg)，解压后通过 `<Reference>` 直接引用 DLL
  - Microsoft.AspNetCore.OData 9.0.0
  - Microsoft.OData.Core 8.0.2
  - Microsoft.OData.Edm 8.0.2
  - Microsoft.OData.ModelBuilder 2.0.0
  - Microsoft.Spatial 8.0.2
- 生成最小 `project.assets.json` 使 MSBuild 跳过 NuGet 恢复步骤
- 设置 `EnableDefaultContentItems=false` 解决重复 Content 项冲突

**API 重构**
- `DynamicEdmModelBuilder` 改用底层 `EdmModel` API（因 ModelBuilder 2.0.0 要求强类型）
- `DynamicODataController` 改用手动 OData 查询解析器（因 `[EnableQuery]` 无法处理 `Dictionary<string, object?>`）
  - 完整实现 `$filter` 表达式解析（eq/ne/gt/lt/ge/le/and/or）
  - 支持函数：`contains()`, `startswith()`, `endswith()`
  - 支持 `$select`, `$orderby`, `$top`, `$skip`, `$count`
- 前后端响应格式对齐（`{ value: [...], count: N }`）

**验证通过的所有测试端点：**
- `GET /odata/Products?$filter=Price gt 5000&$select=Name,Price&$orderby=Price desc&$top=3&$count=true` ✅
- `GET /odata/Products?$filter=contains(Name,'Pro')` ✅
- `GET /odata/Customers?$filter=Level eq 'VIP'` ✅
- `GET /odata/Orders?$filter=Status eq 'Completed'&$select=Id,TotalAmount,Status&$top=3` ✅
- `GET /odata/Products/1` ✅
- `GET /odata/$metadata` ✅
- `GET /odata/admin/entity-sets` ✅

### 构建方式
- 后端：`dotnet build --no-restore` (本地 DLL 引用)
- 前端：`npm run build` (Vite)

### 启动方式
- 一键启动：`start.cmd` (同时启动前后端)
- 或分别启动：
  - 后端：`dotnet run --no-build` (需设置 DOTNET_CLI_HOME 和 ASPNETCORE_URLS)
  - 前端：`cd frontend\app && npm run dev`
